WEBSITE NAJELAAAA — ULTIMATE EDITION
=========================================

CARA MEMBUKA
1. Ekstrak file ZIP.
2. Buka folder website_najelaaaa_ultimate.
3. Klik dua kali index.html.
4. Gunakan Chrome atau Edge.

FITUR UTAMA
- Opening cinematic
- Multi-song playlist
- Previous, next, shuffle, repeat, seek, dan volume
- Pilih beberapa MP3 langsung dari perangkat
- Relationship counter
- Countdown anniversary berikutnya
- Mood message / emotional first aid
- Memory jar dengan pesan acak
- Tambah pesan rahasia sendiri
- Bucket list berdua dengan progress
- Penyimpanan otomatis melalui browser
- Personalisasi nama, tanggal jadian, dan surat tanpa edit HTML
- Tema midnight dan rose-light
- Foto dapat diperbesar
- Generator kartu cinta PNG
- Mini-game tangkap hati
- Surat amplop interaktif
- Easter egg tersembunyi
- Animasi bintang, vinyl, hati, dan confetti

PERSONALISASI TANPA EDIT KODE
Tekan tombol roda gigi (⚙) pada bagian kanan atas.
Nama, tanggal jadian, dan isi surat dapat diubah langsung.
Perubahan disimpan di browser perangkat.

CARA MEMASUKKAN LAGU PERMANEN
Masukkan file berikut ke folder assets:
- love-story.mp3
- perfect.mp3
- until-i-found-you.mp3
- those-eyes.mp3
- here-with-me.mp3

CARA MEMILIH LAGU LANGSUNG
1. Scroll ke playlist.
2. Tekan "Pilih beberapa MP3".
3. Pilih beberapa file sekaligus.
4. Gunakan format nama:
   Nama Penyanyi - Judul Lagu.mp3

CARA MENGGANTI FOTO
Masukkan tiga foto ke folder assets dan beri nama:
- foto1.jpg
- foto2.jpg
- foto3.jpg

Kemudian buka index.html dan ganti:
assets/foto1.svg → assets/foto1.jpg
assets/foto2.svg → assets/foto2.jpg
assets/foto3.svg → assets/foto3.jpg

CATATAN
- Lagu tidak disertakan karena berhak cipta.
- Memory jar, bucket list, tema, dan personalisasi disimpan pada browser.
- Menghapus data browser akan mereset data tersebut.
